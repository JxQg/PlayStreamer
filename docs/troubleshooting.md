# 故障排查

先运行应用内诊断，按“网络配置 → 端口和防火墙 → PS5 DNS 请求 → 直播入口命中 → 媒体接收 → OBS → 目标平台”的顺序检查。可以导出诊断信息供自己查看或提交问题；提交前仍应检查其中的设备地址等环境信息。不要提供 Twitch 或平台推流密钥。

| 现象 | 检查和处理 |
| --- | --- |
| 无法开启接收 | 检查所选网卡仍连接、PS5 IPv4 与电脑同一子网；关闭占用端口的其他接收软件 |
| DNS 端口被占用 | 本地 DNS、代理软件 DNS 模式或另一实例可能使用 TCP/UDP 53；调整冲突软件后重试，不要强制终止不认识的系统进程 |
| RTMP 端口被占用 | 检查是否运行另一份 PlayStreamer、MediaMTX、Nginx RTMP 等；仅保留需要的接收器 |
| PS5 连接测试失败 | 确认 PlayStreamer 正在运行，PS5 首选 DNS 是当前电脑 IP，电脑未休眠；临时恢复 PS5 自动 DNS 判断原网络是否正常 |
| 看不到 PS5 DNS 请求 | 检查 PS5 地址配置、首选 DNS、网络隔离和 Windows 专用网络防火墙；不要把公共 DNS 配成备用入口 |
| 有 DNS 请求但没有直播入口命中 | 先确认 PS5 实际选择 Twitch 开播；账号授权与网络可达性仍需在主机上检查 |
| 入口已命中但无视频 | 检查 TCP 1935、防火墙和主机广播状态；检查客户端版本与 PS5 固件兼容记录 |
| 应用收到视频，OBS 黑屏 | 取消媒体源“本地文件”，确认填写固定本地播放地址；重新激活媒体源并查看音视频轨道 |
| OOPZ 有画面没声音 | 检查 OBS 音频监听设备及 OOPZ 分享声音；虚拟摄像头不会自动传递音频 |
| 出现回声或重复声音 | 避免同一 PS5 音频同时被媒体源与桌面捕获叠加；避免共享 OOPZ 自己的语音回放 |
| 地址变化后失效 | 重新选择正确网卡，并把 PS5 首选 DNS 更新为新的电脑地址；建议使用 DHCP 地址保留 |
| 开启 TUN 后接流失效 | 保持选择物理网卡，检查回环和 PS5 / 电脑局域网流量是否直连；确认代理 DNS 没有占用 53 端口、劫持直播域名或返回 fake-IP |
| 电脑能登录 Twitch，PS5 不能 | 电脑的系统代理或 TUN 通常不自动代理主机；检查路由器或 PS5 已有 HTTP 代理的可达性，单独验证主机上的账号关联与开播 |

## TUN 和代理的检查顺序

保留现有联网方案，从本地链路开始定位，不必把关闭整个代理软件作为固定步骤。

1. 在 PlayStreamer 选择与 PS5 同网段的物理以太网 / Wi-Fi 地址。不要选择 TUN、fake-IP 或虚拟机网卡地址。物理网卡仍有默认路由，不代表 TUN 没有接管流量。
2. 检查 TCP/UDP 53 与 TCP 1935。若代理产品同时提供本地 DNS，应按其文档调整冲突监听或 DNS 劫持规则；不要终止不认识的系统进程。
3. 在代理产品中核实回环地址、电脑 LAN 地址、PS5 地址及该局域网网段的直连规则。检查 PS5 发来的 DNS 请求是否到达本应用，直播入口是否解析到电脑真实 LAN 地址。
4. 检查应用上游 DNS 是否可达且不会指回自身。上游用于普通域名解析，不能填写 HTTP / SOCKS 代理端口。TUN 的 fake-IP 解析结果依赖其对应转发路径，不能假设 PS5 也具备该路径。
5. 本地接流正常而登录失败时，检查 PS5 的互联网出口。若复用电脑已有 HTTP / mixed 代理，确认监听允许 PS5 来源、PS5 填写电脑物理地址与正确端口；仅有 SOCKS 监听不适用于 PS5 的 HTTP 代理设置。

修改代理产品设置后，在 PS5 上分别验证账号服务与广播；HTTP 代理不能保证覆盖主机所有流量。PlayStreamer 不会修改系统代理、路由或自动启用共享转发，不应把 Twitch 登录 / API 的 HTTPS 域名指向本地接流器。

## 无法关联 Twitch 时

当前 DNS 接流不会替代 PSN / Twitch 登录、账号绑定或广播授权；没有经过验证的免登录原生广播方案。已绑定账号仍可能在开播时访问平台。电脑能访问平台也不能证明 PS5 能访问。

如果希望完全不依赖 Twitch，可使用官方 PS Remote Play、chiaki-ng 本地远程游玩或 HDMI 采集卡，把画面直接交给 OBS。官方远程游玩仍需要 PlayStation 账号；chiaki-ng 手动注册仍需要 Account-ID 和主机配对 PIN。详细条件见 [PS5 设置](ps5-setup.md#不使用-twitch-的选择)。这些方式是替代画面来源，不是本版本内置的接流后端。

## 服务边界

- DNS 监听所选局域网地址的 TCP/UDP 53，接受配置的 PS5 以及本机诊断请求。
- RTMP 接收使用 TCP 1935；固定播放地址 `rtmp://127.0.0.1:1935/live/playstation` 供本机 OBS 使用。
- 管理 API 和鉴权服务仅在回环地址的动态端口运行，不需要向局域网或互联网放行。
- 防火墙配置针对应用和指定 PS5 来源；请在可信的专用网络使用，不需要设置路由器公网端口映射。

停止接收保留 DNS；完全退出会停止 DNS。PS5 仍指向电脑 DNS 时，电脑退出、关机或休眠会影响主机解析，请先把 PS5 DNS 恢复自动。
