# 版本与验证

线上正式版本以 [GitHub Releases](https://github.com/JxQg/PlayStreamer/releases/latest) 为准。本地使用已完成测试。工作流结果以 [GitHub Actions](https://github.com/JxQg/PlayStreamer/actions) 为准。

## 正式版本

当前正式版本为 [v0.1.1](https://github.com/JxQg/PlayStreamer/releases/tag/v0.1.1)。版本提供 Windows x64 安装包、`SHA256SUMS` 和 `RELEASE_NOTES.md`。安全修复见[版本说明](https://github.com/JxQg/PlayStreamer/blob/main/docs/releases/0.1.1.md)。

| 项目 | 状态或范围 |
| --- | --- |
| 本地使用 | 已测试 |
| Windows x64 | 正式安装包已发布，当前未签名 |
| Windows CI | 检查前端、核心、桌面编译、网卡和合成媒体 |
| macOS | 核心模块兼容检查，尚无桌面安装包 |
| Linux | 优化构建中的 glib 安全回归检查 |
| 官网 | GitHub Pages 提供在线操作文档 |

发布资产和工作流记录支持核对版本来源。设备固件、账号权限和平台客户端变化可能影响接流。

## 自动检查范围

持续集成（Continuous Integration，CI）和发布工作流覆盖：

| 检查 | 内容 |
| --- | --- |
| 前端 | TypeScript 类型检查和生产构建 |
| 发布流程 | 标签格式、版本一致性、安装包资产和摘要 |
| 网卡 | 缺少 IPv4 或 DNS、多地址和 JSON 数组形状 |
| Rust | 格式、核心 Clippy、核心测试和桌面编译 |
| 合成媒体 | 固定播放路径、不同密钥竞争、断流恢复、端口冲突和进程回收 |
| macOS 核心 | 核心模块编译和测试 |
| Linux 安全补丁 | glib 优化构建回归测试 |
| 官网 | 页面构建、本地链接、资源和锚点 |

Windows 工作流显式启用 MediaMTX 与 FFmpeg 的合成音视频测试。默认核心测试命令会忽略媒体集成测试。运行命令见[维护与发布](releasing.md#合成媒体测试)。

## 设备验收项目

下表用于版本升级后的设备回归。每项记录必须对应实际使用的设备和平台版本。

| 场景 | 验收条件 |
| --- | --- |
| PS5 Twitch 开播 | 直播入口 DNS 命中，应用收到音视频 |
| PS5 重复启停 | 开始和停止广播后可恢复，无旧会话占用 |
| OBS 媒体源 | 固定地址有音画，断流后能恢复 |
| Bilibili 直播 | 独立观看设备收到音画，声音和画面同步 |
| OOPZ 分享 | 独立账号收到投影和 PS5 声音，无回声 |
| OOPZ 窗口状态 | 分别记录投影遮挡、最小化时的输出行为 |
| 持续直播 | 持续时间不小于 60 分钟，无崩溃或遗留进程。断流后能恢复 |
| 网络变化 | 地址变化或网卡断开后有提示，能重新配置 |
| 休眠与唤醒 | 暂停时有不可用提示，唤醒后能恢复接收 |
| 托盘与退出 | 关闭窗口继续接收，退出清理服务并提示恢复 DNS |
| Windows 安装卸载 | 全新用户能安装和启动。卸载时提示恢复 DNS，并清理应用规则 |

## 记录验收结果

前置条件：对应版本已安装，设备和账号已准备完成。

1. 记录应用版本和测试日期。
2. 记录 Windows、PS5 固件、OBS 和目标平台版本。
3. 记录连接方式、网卡和代理配置。
4. 按用户文档执行目标场景。
5. 用独立观看设备验证平台输出。
6. 记录预期结果、实际结果和复现条件。
7. 将结果加入对应版本的验收记录。

构建和自动测试不能代替设备上的平台音画确认。诊断和反馈要求见[故障排查](troubleshooting.md#导出诊断和反馈)。
