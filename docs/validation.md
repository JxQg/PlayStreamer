## 自动检查

2026-11-18 本地 Windows x64 检查记录：前端类型检查与生产构建通过；Rust 格式、核心 Clippy 与桌面编译检查通过；核心测试 18 项通过，需显式启用的媒体集成测试在默认测试命令中保持忽略。另行使用锁定的 MediaMTX v1.21.4 和 FFmpeg 9.0.2 执行合成 H.264/AAC 集成测试通过，覆盖固定路径读取、不同密钥竞争、断流恢复、1935 端口冲突和进程回收。

网络枚举回归脚本通过缺少 IPv4 / DNS、多地址及 JSON 数组形状检查；本机物理以太网与 TUN、Hyper-V 等虚拟网卡共存时，实际 Windows PowerShell 5.1 枚举通过。发布流程行为测试 14 项通过。以上不代表 PS5 实机兼容性、macOS 或远端 GitHub Actions 已验证；窗口视觉与托盘行为仍按上表执行人工验收。

每次提交和拉取请求运行 Windows 前端类型检查/构建、发布流程行为测试、Rust 格式检查、核心 clippy/测试和桌面编译检查；macOS 运行核心编译检查/测试。Windows CI 还会安装 FFmpeg，并显式运行需要 MediaMTX 的合成音视频集成测试，不将它永久跳过。版本发布会重新运行这些检查，再生成 Windows NSIS 安装包。实际执行结果以对应 GitHub Actions 运行记录为准。

媒体测试应覆盖来源限制、固定播放路径、单一发布会话、缺少/错误凭据、断开释放与脱敏日志。网络测试应覆盖目标域名与普通 DNS 转发、非 PS5 来源拒绝、上游失败，以及停止后资源释放。
