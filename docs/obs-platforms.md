# OBS 与转播平台设置

先按[快速开始](quick-start.md)完成本地接流，确认 PlayStreamer 已显示“正在接收”，再配置 OBS 与目标平台。

## 添加 PS5 媒体源

1. 安装并打开 [OBS Studio](https://obsproject.com/)，新建专用于 PS5 的场景。
2. 在“来源”点击“+ → 媒体源”，命名为“PS5”。取消勾选“本地文件”。
3. 输入 `rtmp://127.0.0.1:1935/live/playstation` 并确定。先开启 PlayStreamer 接收，再让 PS5 开始广播。
4. 确认预览有画面，音频混音器中 PS5 来源有电平。根据广播分辨率设置画布，必要时对来源使用“变换 → 适配屏幕”。
5. 先录制一段本地视频检查画面、声音与同步，再配置转播平台。

如果播放断开，先确认 PlayStreamer 仍在接收。OBS 媒体源可重新连接或重新激活；具体行为应按使用的 OBS 版本验证。不要把这个本地地址填入“设置 → 直播”的服务器栏。

## Bilibili

在 [Bilibili 直播中心](https://link.bilibili.com/p/center/index#/my-room/start-live) 按账号要求完成开播资格、分区与房间设置，取得当前可用的服务器地址和推流码。平台权限、推流码有效期和界面可能变化，以自己账号的官方页面为准。

在 OBS“设置 → 直播”选择 Bilibili 或自定义服务，按平台给出的服务器和推流码填写。不要公开推流码、把它放进截图或提交到仓库。PlayStreamer 不需要 Bilibili 密钥。

输出编码、分辨率、帧率、码率和关键帧间隔按照平台当前要求及电脑性能选择。先检查本地录制，再点击 OBS“开始直播”，从另一台设备打开直播间验证声音和画面。平台额外的网络和处理延迟不等于本地接收延迟。

参考：[Bilibili 官方工具教程](https://link.bilibili.com/p/help/index?id=4#/tools-tutorial)。

## OOPZ

OOPZ 使用窗口/屏幕分享路径。本项目不要求、也不提供未经官方确认的 OOPZ RTMP 推流地址。

1. 在 OBS 右键预览或场景，打开“窗口化投影”。让该窗口只展示希望分享的节目画面。
2. 在 OOPZ 进入具有分享权限的语音频道，启动屏幕分享，并选择 OBS 投影窗口；若界面提供分享声音选项，将其开启。
3. 在 OBS“高级音频属性”检查 PS5 来源的音频监听，并在 OBS 音频设置中选择需要的监听设备。仅有混音器电平并不表示音频已经输出到 OOPZ 能捕获的设备。
4. 请另一位成员或另一台设备确认画面和声音，检查音量、回声与重复音轨。完成验证前不要只凭本机预览判断分享成功。

不同 OOPZ/OBS 版本的窗口音频捕获行为可能不同。如果有画面无声音，先确认 OBS 监听设备可以听到 PS5 声音，再检查 OOPZ 共享声音与输入设备。避免让 OOPZ 的语音回放再次进入共享音频；使用耳机能减少声学回声。不要仅为解决问题盲目开启多个桌面音频来源。

OBS 虚拟摄像头只提供视频，不自动附带混音音频。仅在目标客户端支持摄像头选择且已经安排好独立音频路径时使用它。虚拟音频设备属于进阶配置，不是首版默认依赖。

OOPZ 完整音画链路、窗口最小化或遮挡时的行为须在实际客户端上验证，状态记录于[验证清单](validation.md)。

参考：[OBS 投影窗口](https://obsproject.com/kb/power-of-projectors)、[OBS 虚拟摄像头](https://obsproject.com/kb/virtual-camera-guide)、[OOPZ 官网](https://oopz.cn/)。
