# 快速开始

本指南用于首次连接 PS5、PlayStreamer 和 OBS Studio（下文简称 OBS）。完成后，OBS 能读取主机画面和声音。转播目标为 Bilibili 或 OOPZ。

## 开始前准备

| 项目 | 前置条件 |
| --- | --- |
| 电脑 | Windows 10 22H2 或 Windows 11，x64 架构 |
| 网络 | PS5 与电脑位于同一 IPv4 子网，建议使用网线 |
| 账号 | PS5 能访问 PlayStation Network（PSN）和 Twitch |
| OBS | 同一台电脑已安装 [OBS Studio](https://obsproject.com/) |
| 转播权限 | Bilibili 账号有开播权限，或 OOPZ 账号有频道分享权限 |

macOS 尚无桌面安装包。正式版本和测试范围见[版本与验证](validation.md)。电脑在接收期间必须保持开机且不休眠。

## 下载和安装

安装包包含 MediaMTX 接流组件。Microsoft Edge WebView2 Runtime 是客户端运行组件。缺少 WebView2 时，安装程序需要联网下载。

警告：安装包尚未签名，Windows 可能提示未知发布者。摘要不一致时必须停止安装。

1. 打开 [GitHub 最新版本](https://github.com/JxQg/PlayStreamer/releases/latest)。
2. 下载文件名以 `_windows_x64_setup.exe` 结尾的安装包。
3. 下载同一版本的 `SHA256SUMS`。
4. 在下载目录运行摘要检查命令。

   ```powershell
   Get-ChildItem -File -Filter 'PlayStreamer_*_windows_x64_setup.exe' | Get-FileHash -Algorithm SHA256
   ```

5. 将安装包摘要与 `SHA256SUMS` 中同名文件的摘要比较。
6. 如果摘要一致，运行安装包。
7. 按安装向导完成安装。

## 完成连接向导

PS5 的「设置 → 网络 → 连接状态 → 查看连接状态」显示 IPv4 地址。电脑网卡必须连接 PS5 所在的物理局域网。

域名系统（Domain Name System，DNS）负责解析联网域名。「上游 DNS」使用当前网络可达的 IPv4 DNS 地址。电脑自身地址、HTTP 代理端口和 SOCKS 代理端口不适用。

本指南先保存连接参数，再配置防火墙和 PS5 DNS。向导中的 PS5 和 OBS 步骤由后续章节说明。

1. 在 PS5 的「查看连接状态」记录 IPv4 地址。
2. 启动 PlayStreamer。

   系统首次启动时显示连接向导。

3. 在「电脑网卡」选择物理以太网或 Wi-Fi 网卡。
4. 在「PS5 的 IPv4 地址」填写主机地址。
5. 检查「上游 DNS」中的地址。
6. 如果地址为空，填写可达的 IPv4 DNS 地址。
7. 点击「下一步」。
8. 点击「下一步」。
9. 点击「完成设置」。

已完成向导时，连接参数位于「设置与诊断」的「连接设置」。修改规则见[停止和恢复](ps5-setup.md#停止和恢复)。

建议在路由器中为电脑和 PS5 保留动态主机配置协议（DHCP）地址。地址保留能减少重启后的地址变化。

电脑上的 TUN 虚拟网卡或虚拟专用网络（VPN）可继续使用。接流仍使用物理网卡，局域网流量必须直连。PS5 复用电脑代理的条件见[代理共存说明](ps5-setup.md#与-tunvpn-和现有代理共存)。

## 启动接收和设置 DNS

前置条件：电脑连接可信局域网，Windows 网络配置为「专用网络」。

1. 打开 PlayStreamer 的「设置与诊断」。
2. 点击「开始检查」。
3. 如果诊断提示防火墙未配置，点击「配置防火墙」。
4. 如果 Windows 请求权限，完成权限确认。
5. 返回 PlayStreamer 首页。
6. 点击「开启接收」。

   系统显示「等待主机开播」。

7. 记录首页「PS5 首选 DNS」显示的电脑地址。
8. 在 PS5 打开「设置 → 网络 → 设置 → 设置互联网连接」。
9. 打开当前网络的「高级设置」。
10. 将「DNS 设置」改为「手动」。
11. 将「首选 DNS」设为第 7 步的电脑地址。
12. 将「次选 DNS」设为主机允许的空值或 `0.0.0.0`。
13. 保存网络设置。
14. 运行 PS5 网络连接测试。

次选 DNS 使用公共 DNS 时，PS5 可能绕过本地解析。IP 地址、DHCP、MTU 和已验证可用的代理设置沿用原值。PS5 菜单名称可能随系统版本变化。

「配置防火墙」仅允许指定 PS5 访问本地 DNS 和媒体接收端口。应用不会为其他代理软件放行端口。局域网接流无需路由器公网端口映射。

## 在 PS5 发起广播

前置条件：PlayStreamer 显示「等待主机开播」。PS5 能访问 PSN 和 Twitch。

1. 在 PS5 打开「设置 → 用户和账号 → 已关联的服务」。
2. 关联 Twitch 账号。
3. 完成 Twitch 要求的验证。
4. 启动要广播的游戏。
5. 按手柄的创建按钮。
6. 选择「广播 → Twitch」。
7. 按主机提示开始广播。
8. 检查 PlayStreamer 首页的接收状态。

   系统收到媒体流后显示「正在接收」。

如果状态保持「等待主机开播」，按[故障排查](troubleshooting.md)检查 DNS 计数和直播域名命中。

本地接流仍依赖 Twitch 账号关联和开播授权。其他画面来源见 [PS5 设置](ps5-setup.md#不使用-twitch-的选择)。

## 在 OBS 添加画面和声音

前置条件：PlayStreamer 显示「正在接收」，OBS 与 PlayStreamer 位于同一台电脑。

1. 启动 OBS。
2. 新建 PS5 场景。
3. 在「来源」中添加「媒体源」。
4. 取消勾选「本地文件」。
5. 在「输入」中填写本地播放地址。

   ```text
   rtmp://127.0.0.1:1935/live/playstation
   ```

6. 点击「确定」。
7. 检查 OBS 预览中的 PS5 画面。
8. 检查音频混音器中的 PS5 来源电平。
9. 按 [OBS 设置](obs-platforms.md#检查本地录制)检查本地录制。

本地播放地址使用实时消息传输协议（RTMP）。`127.0.0.1` 表示当前电脑。这个地址只用于同机 OBS 的媒体源「输入」。

| 地址或参数 | 用途 |
| --- | --- |
| 电脑物理局域网 IPv4 地址 | PS5 的「首选 DNS」 |
| `rtmp://127.0.0.1:1935/live/playstation` | OBS 媒体源的「输入」 |
| Bilibili 服务器地址和推流码 | OBS 的「设置 → 直播」 |
| 电脑代理地址和 HTTP / mixed 端口 | PS5 的代理服务器设置 |

「正在读取」显示读取客户端数。这个数值不识别 OBS，也不代表平台观众已收到音画。

## 选择转播方式

| 目标 | 设置文档 | 验收条件 |
| --- | --- | --- |
| Bilibili | [Bilibili 设置](obs-platforms.md#bilibili) | 独立观看设备收到画面和声音，音画同步 |
| OOPZ | [OOPZ 设置](obs-platforms.md#oopz) | 其他成员看到投影画面，听到声音且无回声 |

PlayStreamer 不保存平台推流码。OOPZ 使用 OBS 投影窗口分享。OBS 虚拟摄像头只提供视频。

## 日常启动和停止

### 再次开播

前置条件：电脑和 PS5 的地址、网卡及 DNS 配置未变。

1. 启动 PlayStreamer。
2. 点击「开启接收」或「重新开启接收」。
3. 在 PS5 开始 Twitch 广播。
4. 确认 PlayStreamer 显示「正在接收」。
5. 检查 OBS 的画面和声音。
6. 启动目标平台的直播或分享。

### 停止接收

1. 结束目标平台的直播或分享。
2. 在 PS5 结束广播。
3. 在 PlayStreamer 中点击「停止接收」。

系统停止媒体接收，DNS 继续运行。界面显示「仅 DNS 运行中」。关闭窗口只会隐藏到系统托盘。

### 完全退出

警告：完全退出、休眠和关机会停止 DNS。PS5 DNS 仍指向电脑时，主机可能无法解析域名。

1. 按上一节停止接收。
2. 将 PS5 的「DNS 设置」恢复为「自动」。
3. 在 PlayStreamer 托盘菜单中点击「退出」。
4. 如果显示退出确认，点击「退出应用」。

网络或地址变化后的步骤见 [PS5 设置](ps5-setup.md#停止和恢复)。诊断和反馈步骤见[故障排查](troubleshooting.md#导出诊断和反馈)。
