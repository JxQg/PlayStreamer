# 快速开始

这份指南带你完成第一次连接：让 PS5 的广播进入 PlayStreamer，再由同一台电脑上的 OBS 读取画面，转播到 Bilibili 或分享到 OOPZ。完成首次设置后，日常使用只需开启接收、在 PS5 开播，再启动 OBS。

## 开始前准备

| 项目 | 需要准备的内容 |
| --- | --- |
| 电脑 | Windows 10 22H2 / Windows 11 x64，直播期间保持开机并避免休眠 |
| 主机与网络 | PS5 与电脑连接同一路由器，位于同一 IPv4 子网，建议使用网线 |
| 账号与联网 | PS5 可访问 PSN、Twitch，能够关联 Twitch 账号并发起广播 |
| 播放与转播 | 同机安装 [OBS Studio](https://obsproject.com/)，按需要准备 Bilibili 开播资格或 OOPZ 账号 |

当前提供 Windows 安装包，macOS 尚无桌面发行版。真实 PS5 固件、OBS 和目标平台的联合验证状态见[兼容性与验证记录](validation.md)，请先核对自己的使用条件。

## 1. 下载并安装

从 [GitHub 最新版本](https://github.com/JxQg/PlayStreamer/releases/latest) 下载文件名以 `_windows_x64_setup.exe` 结尾的安装包，按安装向导完成安装。`SHA256SUMS` 可用于核对下载文件的完整性。

安装包已包含本地接流组件，无需另行安装 MediaMTX 或手工配置接流服务器。客户端需要 Microsoft Edge WebView2 Runtime；电脑缺少该组件时，安装程序需要联网安装它。当前安装包未进行代码签名，Windows 可能显示未知发布者或 SmartScreen 提示；请先核对下载来源与文件摘要，再决定是否运行。

## 2. 选择电脑与 PS5 的局域网地址

1. 在 PS5 打开“设置 → 网络 → 连接状态 → 查看连接状态”，记下主机的 IPv4 地址。
2. 打开 PlayStreamer，点击“设置并开启接收”，在向导中选择连接 PS5 所在网络的物理以太网或 Wi-Fi 网卡。已完成向导时，可在“设置与诊断 → 连接设置”查看配置。
3. 填入刚才记下的 PS5 IPv4 地址。选择的电脑地址必须能从 PS5 所在局域网访问，不能使用 `127.0.0.1`、TUN、VPN 或虚拟机网卡地址。
4. 检查“上游 DNS”。它用于解析普通联网域名；若未检测到可用值，填写当前网络可达的 IPv4 DNS 地址。不要填写电脑自身的接流地址、HTTP 代理端口或 SOCKS 端口。
5. 继续向导保存配置。建议在路由器中为电脑和 PS5 保留 DHCP 地址，避免重启后地址变化。

**电脑使用 TUN / VPN 时**：可保留现有代理，但接流仍选物理局域网网卡，并确保电脑与 PS5 的局域网流量直连。仅在电脑开启 TUN，并不会自动让 PS5 访问 Twitch。若希望 PS5 复用电脑已有的 HTTP / mixed 代理，请按 [PS5 网络与代理设置](ps5-setup.md) 配置并在主机上验证；HTTP 代理不保证覆盖全部主机流量。

## 3. 开启接收并设置 PS5 DNS

1. 在可信的家庭局域网使用 Windows“专用网络”。进入 PlayStreamer“设置与诊断 → 运行诊断”，点击“开始检查”。
2. 按需点击“配置防火墙”，完成 Windows 的权限提示。该操作允许配置的 PS5 访问本地 DNS 与 RTMP 接收端口，不会为其他代理软件开放端口。
3. 点击“开启接收”，确认应用显示“等待主机开播”。向导中的“开启接收”按钮也可完成这一步。
4. 在 PS5 打开“设置 → 网络 → 设置 → 设置互联网连接”，选择当前网络的“高级设置”，将 DNS 设置改为“手动”。
5. **首选 DNS** 填入 PlayStreamer 显示的电脑物理局域网 IPv4 地址。**次选 DNS** 按当前 PS5 界面允许的方式留空或填 `0.0.0.0`，不要填写公共 DNS，以免主机绕过本地接流解析。
6. 保留原有 IP、DHCP、MTU 与已经验证可用的代理设置。保存并测试连接。

不需要设置路由器公网端口映射。菜单名称可能随 PS5 系统版本变化，详细说明见 [PS5 设置](ps5-setup.md)。

## 4. 在 PS5 发起广播

在 PS5“设置 → 用户和账号 → 已关联的服务”关联 Twitch，并完成平台要求的验证。按手柄的创建按钮，选择“广播 → Twitch”，设置广播内容后开始播送。

回到 PlayStreamer，确认状态从“等待主机开播”变为“正在接收”。若没有变化，先看“设置与诊断”中的 DNS 查询与直播域名命中，再按[故障排查](troubleshooting.md)定位问题。

当前接流方式仍需要 Twitch 关联与开播授权，不能绕过账号登录。无法满足这一条件时，可考虑远程游玩或 HDMI 采集卡作为 OBS 的其他输入来源，具体条件见 [PS5 设置](ps5-setup.md)。

## 5. 让 OBS 读取画面与声音

1. 在 OBS 新建场景，在“来源”中点击“+ → 媒体源”。
2. 取消勾选“本地文件”，把 PlayStreamer 首页复制的地址填入“输入”：

```text
rtmp://127.0.0.1:1935/live/playstation
```

3. 确认 OBS 出现 PS5 画面，音频混音器中的 PS5 来源有电平。必要时对来源选择“变换 → 适配屏幕”。
4. 先录制一段本地视频，回放检查声音、画面与同步，再向平台转播。

下列地址用途不同，不能互换：

| 地址或设置 | 应填在哪里 |
| --- | --- |
| 电脑物理局域网 IPv4 | PS5 的首选 DNS |
| `rtmp://127.0.0.1:1935/live/playstation` | 同机 OBS 的媒体源“输入” |
| Bilibili 服务器地址与推流码 | OBS“设置 → 直播” |
| 已有代理的电脑地址与 HTTP / mixed 端口 | 需要复用代理时，填入 PS5 的代理服务器设置 |

PlayStreamer 的“正在读取”显示客户端数量，仅说明有客户端正在读取，不代表已识别 OBS，也不代表平台观众已收到画面。

## 6. 选择转播方式

| 目标 | 操作 | 确认结果 |
| --- | --- | --- |
| Bilibili | 在官方直播中心获取服务器地址与推流码，在 OBS“设置 → 直播”填写，再由 OBS 开始直播 | 用另一台设备打开直播间，确认画面、声音与同步 |
| OOPZ | 在 OBS 打开窗口化投影，在 OOPZ 分享这个窗口，并检查共享声音与 OBS 音频监听 | 让另一位成员或另一台设备确认画面、声音及无回声 |

PlayStreamer 不保存平台推流码；不要在截图、问题报告或公开仓库中泄露它们。OOPZ 使用投影窗口分享路线，不能把本地 RTMP 地址当作 OOPZ 推流地址。OBS 虚拟摄像头不会自动传递音频。完整操作见 [OBS、Bilibili 与 OOPZ 设置](obs-platforms.md)。

## 7. 正确停止与日常使用

下次开播时，先打开 PlayStreamer 并开启接收，再在 PS5 开始广播，最后确认 OBS 画面和声音。

- **关闭窗口**：应用隐藏到系统托盘，继续运行。点击托盘图标可恢复窗口，也可从托盘菜单控制接收。
- **停止接收**：先在 PS5 结束广播，再停止接收。应用会保留 DNS 服务，界面可显示“仅 DNS 运行中”。
- **完全退出、重启或关机**：先结束 PS5 广播，把 PS5 DNS 恢复“自动”，再退出应用。电脑退出、关机或休眠后，无法继续为 PS5 提供 DNS。
- **网络或地址变化**：重新核对电脑网卡与 PS5 IPv4，并更新 PS5 首选 DNS。直播期间避免电脑休眠。

遇到问题先运行诊断，再查看[故障排查](troubleshooting.md)。如需[提交问题](https://github.com/JxQg/PlayStreamer/issues)，请说明应用版本、Windows / PS5 / OBS 版本、连接方式和复现步骤；导出诊断后检查环境信息，勿附账号凭据或直播密钥。
