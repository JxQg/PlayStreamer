# PS5 设置

## 准备网络和账号

电脑和 PS5 必须位于同一 IPv4 子网。优先使用有线连接；访客 Wi-Fi、客户端隔离和不同 VLAN 可能阻止 PS5 访问电脑。建议在路由器中为两台设备保留 DHCP 地址，避免重启后地址变化。

在 PS5 的“设置 → 网络 → 连接状态 → 查看连接状态”记录 IPv4 地址。在 PlayStreamer 选择连接该网络的物理以太网或 Wi-Fi 网卡，填入 PS5 地址并保存。不要选择代理 TUN、VPN、虚拟机或未连接的网卡；代理的虚拟地址不能作为 PS5 访问电脑的局域网入口。

在 PS5“设置 → 用户和账号 → 已关联的服务”关联 Twitch，完成服务要求的验证。菜单名称可能随系统版本变化。关联和开始广播仍依赖 PS5 能够访问 PSN、Twitch 的相关服务；电脑可以访问不代表主机也能访问。

## 与 TUN、VPN 和现有代理共存

本地接流与账号联网是两条链路：PS5 通过物理局域网访问电脑的 DNS 和 RTMP；PSN / Twitch 的登录、关联和开播请求仍需要可用的互联网出口。PlayStreamer 不会自动关闭 TUN，也不会修改系统 DNS、代理或路由。

- **接流保持局域网直达**：按代理产品的配置方式，让回环地址、电脑局域网地址、PS5 地址及对应局域网网段直连。若产品有“允许局域网”或绕过局域网选项，确认其行为符合当前网络。不要把本地 RTMP 送往远端代理。
- **避免 DNS 冲突**：TUN 的 DNS 劫持、本地 DNS 服务或其他程序可能占用 TCP/UDP 53，或把直播入口返回成 fake-IP。先在应用诊断中检查端口和直播域名命中；直播入口必须返回选定电脑的真实局域网地址。
- **上游 DNS 只负责解析**：应用中的上游 DNS 不是 HTTP / SOCKS 代理地址。优先使用当前网络可达、返回真实地址且不会转回本应用的解析器。不要直接照抄 TUN 的虚拟 DNS 地址；fake-IP 只有在请求它的设备也具备相应转发路径时才能使用。
- **复用已有联网方式**：如果路由器已经为 PS5 提供正常网络，保留现有设置。仅在电脑开启 TUN，通常不会自动接管 PS5 的互联网流量；主机还需要路由器转发或已配置的代理入口。

复用电脑已有代理时，按以下顺序配置：

1. 在代理产品中找到实际的 **HTTP 或 mixed 监听端口**，按该产品文档开启“允许局域网”。只监听 `127.0.0.1` 的入口无法被 PS5 访问，PS5 的代理设置也不能填写仅支持 SOCKS 的端口。
2. 核实代理允许来自 PS5 地址的连接，并按代理产品文档配置对应的 Windows 入站规则。PlayStreamer 的“配置防火墙”只处理本地 DNS 和 RTMP，不会放行代理产品的端口。无需公网端口映射。
3. 在 PS5 当前网络的“高级设置 → 代理服务器”选择“使用”，服务器填写 PlayStreamer 显示的**电脑物理局域网 IPv4**，端口填写第 1 步查到的值。不要填写 `127.0.0.1`、TUN 地址或把 HTTP URL 整段填入地址栏。
4. 保留本节的局域网直连规则，再按下一节设置首选 DNS。在 PS5 上分别测试 PSN 登录、Twitch 关联和开始广播；在 PlayStreamer 中确认 DNS 命中和收到音视频。

代理应仅对 PS5 或可信局域网开放。代理监听与 PS5 登录由现有代理产品及主机设置完成，PlayStreamer 不保存其凭据。

PS5 的 HTTP 代理并不保证覆盖所有协议或广播控制请求，需要在主机上实际验证账号关联和开播。此功能由现有代理产品提供，PlayStreamer 本身不提供代理转接。已能工作的代理设置无需改成“不使用”；仍应确保直播入口解析和 TCP 1935 保持本地直连。

## 开启接收并修改 DNS

1. 让 Windows 当前网络处于可信的“专用网络”，在 PlayStreamer 中运行诊断。
2. 必要时点击“配置防火墙”并完成 Windows 权限提示，允许指定 PS5 访问应用所需端口。
3. 点击“开启接收”，确认进入等待 PS5 开播状态。
4. 在 PS5“设置 → 网络 → 设置 → 设置互联网连接”选择当前网络，打开“高级设置”。
5. IP 地址、DHCP、MTU 和已经验证可用的代理设置保持原值；仅把 DNS 改为“手动”。未配置代理时保留“不使用”；需要复用电脑代理时，先按上一节核实其局域网监听。
6. 首选 DNS 填入 PlayStreamer 显示的电脑 IPv4 地址；次选 DNS 留空或填 `0.0.0.0`，以当前 PS5 界面允许的形式为准。不要填写公共 DNS 作为次选，否则 PS5 可能绕过本地直播入口解析。
7. 保存后测试连接。再通过 PS5 创建按钮选择“广播 → Twitch”，按需要设置画质并开始广播。

当应用显示正在接收时，在 OBS 使用以下本地媒体源地址：

```text
rtmp://127.0.0.1:1935/live/playstation
```

该地址用于本机 OBS 播放，不是 PS5 上填写的 DNS 地址，也不是 Bilibili 的推流地址。

## 不使用 Twitch 的选择

当前接流模式不能跳过 Twitch 关联。PlayStation 官方说明原生广播需要关联所选服务；DNS 重定向只改变媒体流的目的地，不会产生服务令牌或替代开播授权。仅把登录域名指向电脑也无法完成 HTTPS 证书校验与真实平台授权。当前没有经过验证的、适用于未改装 PS5 的免账号原生广播方案；已关联过账号也不代表以后开播可以一直离线。

如果无法为 PS5 提供 Twitch 可达性，可以选择其他视频来源：

| 方式 | 是否需要 Twitch | 接入方式与条件 |
| --- | --- | --- |
| 官方 PS Remote Play | 不需要 | Windows / macOS 远程游玩后由 OBS 捕获窗口；仍需 PlayStation 账号、开启远程游玩并完成登录或设备配对 |
| chiaki-ng 本地远程游玩 | 不需要 | 按上游文档使用 PSN Account-ID 与主机配对 PIN 手动注册，再由 OBS 捕获；手动本地注册可不经过客户端的 PSN 网页登录，但仍有账号标识和设备认证 |
| HDMI 采集卡 | 不需要 | PS5 HDMI 输出接兼容采集卡，在 OBS 添加视频采集设备；需要额外硬件，受保护视频不可采集 |

这些是 OBS 的替代输入来源，不经过本版本 PlayStreamer 的 RTMP 接收功能。远程游玩的画质、延迟、控制器和音频行为需要按实际设备验证；采集卡按厂商的 PS5 兼容设置配置。

参考：[PlayStation 广播说明](https://www.playstation.com/en-us/support/games/ps5-stream-gameplay-broadcast/)、[官方 PC / Mac 远程游玩](https://www.playstation.com/en-us/support/games/playstation-remote-play-on-pc-and-mac/)、[chiaki-ng 配置说明](https://chiaki-ng.github.io/chiaki-ng/setup/configuration/)。

## 停止和恢复

先在 PS5 结束广播，再停止接收。PlayStreamer 停止接收时继续提供 DNS 解析；可以关闭窗口，让应用留在托盘中。

完全退出应用、重启或关闭电脑前，请把 PS5 的 DNS 恢复为“自动”。如果电脑 IP 或网络变化，需要在应用重新选择网卡，并更新 PS5 首选 DNS 后再开播。电脑休眠期间不能为 PS5 提供 DNS 或接收服务，直播时应避免休眠。

本接收方式依赖 PS5 当前广播入口的行为。若固件或平台切换到无法兼容的协议，诊断和文档不能替代真实设备验证；检查项目版本说明和[实机验证记录](validation.md)。
