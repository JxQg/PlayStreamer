# PS5 设置

本文说明 PS5 的网络、账号、代理和恢复步骤。首次安装见[快速开始](quick-start.md)。OBS 接入见 [OBS 与转播平台设置](obs-platforms.md)。

## 准备网络和账号

前置条件：

- PS5 与电脑位于同一 IPv4 子网。
- 电脑使用物理以太网或 Wi-Fi 网卡，建议使用网线。
- PS5 能访问 PlayStation Network（PSN）和 Twitch。
- PlayStreamer 已保存电脑网卡、PS5 地址和上游 DNS。

访客 Wi-Fi、客户端隔离或虚拟局域网（VLAN）可能阻止设备互通。建议在路由器中保留电脑和 PS5 的动态主机配置协议（DHCP）地址。

域名系统（Domain Name System，DNS）负责把域名解析为地址。PlayStreamer 把直播入口解析到电脑，普通域名转发给上游 DNS。PSN 登录、Twitch 关联和广播授权仍由平台完成。

1. 在 PS5 打开「设置 → 网络 → 连接状态 → 查看连接状态」。
2. 记录主机 IPv4 地址。
3. 核对 PlayStreamer 中「PS5 的 IPv4 地址」。
4. 如果地址不同，按[停止和恢复](#停止和恢复)修改配置。
5. 在 PS5 打开「设置 → 用户和账号 → 已关联的服务」。
6. 关联 Twitch 账号。
7. 完成 Twitch 要求的验证。

电脑能访问 Twitch，不能证明 PS5 也能访问。已关联账号仍可能在开播时访问平台。PS5 菜单名称可能随系统版本变化。

## 与 TUN、VPN 和现有代理共存

TUN 虚拟网卡和虚拟专用网络（VPN）可与接流共存。PlayStreamer 不修改系统代理、DNS 或路由。电脑代理与 PS5 的联网出口需要分别验证。

| 对象 | 配置要求 |
| --- | --- |
| 接流网卡 | 物理以太网或 Wi-Fi。回环、TUN 和虚拟机地址不适用 |
| 本地流量 | 回环地址、电脑局域网地址、PS5 地址和所在网段保持直连 |
| 直播域名 | 返回电脑真实局域网地址，避免虚拟地址应答（fake-IP） |
| 上游 DNS | 可达的 IPv4 DNS 服务器。不能转回本应用 |
| DNS 监听 | 代理产品的 DNS 监听和劫持规则须避免与本应用冲突 |
| PS5 联网 | 路由器提供出口，或 PS5 使用已配置的 HTTP 代理 |

上游 DNS 只负责域名解析，不是代理入口。仅在电脑启用 TUN，不会自动代理 PS5。PS5 使用 fake-IP 时，还需要匹配的流量转发路径。

### 复用电脑上的 HTTP 代理

前置条件：

- 代理产品提供 HTTP 或 mixed 监听端口。
- 监听地址允许 PS5 访问，且不只监听 `127.0.0.1`。
- Windows 入站规则允许 PS5 访问代理端口。

警告：代理端口对非可信设备开放可能造成未授权使用。代理访问范围应限于 PS5 或可信局域网。

1. 在代理产品中记录 HTTP 或 mixed 端口。
2. 按代理产品文档启用局域网访问。
3. 核对代理端口的 Windows 入站规则。
4. 在 PS5 打开当前网络的「高级设置」。
5. 将「代理服务器」设为「使用」。
6. 在服务器地址中填写电脑物理局域网 IPv4 地址。
7. 在端口中填写第 1 步记录的值。
8. 保存代理设置。
9. 按[启动接收并修改 DNS](#启动接收并修改-dns)设置 DNS。

服务器地址只填写 IPv4 地址，不填写完整 HTTP URL。仅支持 SOCKS 的端口不适用于 PS5 的 HTTP 代理设置。

PlayStreamer 的「配置防火墙」只放行 DNS 和媒体接收端口。代理端口由代理产品维护。局域网代理无需路由器公网端口映射。

### 验证主机联网

PS5 的 HTTP 代理可能无法覆盖全部协议和广播控制请求。已验证可用的联网方案可继续使用。PlayStreamer 不保存代理凭据，也不提供代理转接。

1. 在 PS5 验证 PSN 登录。
2. 在 PS5 验证 Twitch 账号关联。
3. 按[开始广播](#开始广播)发起 Twitch 广播。
4. 检查 PlayStreamer 的 DNS 计数和接收状态。

## 启动接收并修改 DNS

前置条件：电脑连接可信的 Windows「专用网络」。连接设置已保存。

1. 在 PlayStreamer 打开「设置与诊断」。
2. 点击「开始检查」。
3. 如果诊断提示防火墙未配置，点击「配置防火墙」。
4. 如果 Windows 请求权限，完成权限确认。
5. 返回 PlayStreamer 首页。
6. 点击「开启接收」。

   系统显示「等待主机开播」。

7. 记录「PS5 首选 DNS」显示的电脑地址。
8. 在 PS5 打开「设置 → 网络 → 设置 → 设置互联网连接」。
9. 打开当前网络的「高级设置」。
10. 将「DNS 设置」改为「手动」。
11. 将「首选 DNS」设为第 7 步的电脑地址。
12. 将「次选 DNS」设为主机允许的空值或 `0.0.0.0`。
13. 保存网络设置。
14. 运行 PS5 网络连接测试。

IP 地址、DHCP、MTU 和已验证可用的代理设置沿用原值。公共次选 DNS 可能让 PS5 绕过本地解析。

## 开始广播

1. 启动要广播的游戏。
2. 按手柄的创建按钮。
3. 选择「广播 → Twitch」。
4. 按主机提示开始广播。
5. 检查 PlayStreamer 首页的接收状态。

系统收到媒体流后显示「正在接收」。同机 OBS 使用固定播放地址：

```text
rtmp://127.0.0.1:1935/live/playstation
```

这个地址是实时消息传输协议（RTMP）播放地址。地址用途和 OBS 步骤见 [OBS 与转播平台设置](obs-platforms.md)。

## 不使用 Twitch 的选择

当前接流模式仍需 Twitch 关联和开播授权。DNS 重定向只改变媒体流目的地。把登录域名指向电脑无法替代平台授权和 HTTPS 证书校验。

项目尚无已验证的免账号原生广播方案。已关联账号不代表后续广播始终支持离线启动。

| 方式 | Twitch 要求 | 接入条件 |
| --- | --- | --- |
| 官方 PS Remote Play | 不需要 | PlayStation 账号、远程游玩配置及登录或设备配对。OBS 捕获远程游玩窗口 |
| chiaki-ng 本地远程游玩 | 不需要 | PSN Account-ID 和主机配对 PIN。手动注册仍需设备认证，OBS 捕获窗口 |
| HDMI 采集卡 | 不需要 | 兼容采集卡和 HDMI 连接。OBS 添加视频采集设备，受保护内容不可采集 |

这些方式直接向 OBS 提供画面，不经过本版本的 RTMP 接收。画质、延迟、控制器和声音需要在实际设备上验证。

参考：[PlayStation 广播说明](https://www.playstation.com/en-us/support/games/ps5-stream-gameplay-broadcast/)、[官方 PC / Mac 远程游玩](https://www.playstation.com/en-us/support/games/playstation-remote-play-on-pc-and-mac/)和 [chiaki-ng 配置说明](https://chiaki-ng.github.io/chiaki-ng/setup/configuration/)。

## 停止和恢复

### 停止媒体接收

1. 在 PS5 结束广播。
2. 在 PlayStreamer 中点击「停止接收」。

系统停止媒体接收，DNS 继续运行。关闭窗口只会隐藏到系统托盘。

### 完全退出、重启或关机

警告：完全退出、休眠和关机会停止 DNS。PS5 DNS 仍指向电脑时，主机可能无法解析域名。

1. 按上一节停止媒体接收。
2. 将 PS5 的「DNS 设置」恢复为「自动」。
3. 在 PlayStreamer 托盘菜单中点击「退出」。
4. 如果显示退出确认，点击「退出应用」。

### 修改网卡、主机地址或上游 DNS

DNS 运行期间，应用锁定网络配置。「停止接收」仍保留 DNS，无法解除配置锁定。

1. 在 PS5 结束广播。
2. 将 PS5 的「DNS 设置」恢复为「自动」。
3. 在 PlayStreamer 托盘菜单中点击「退出」。
4. 如果显示退出确认，点击「退出应用」。
5. 重新启动 PlayStreamer。
6. 打开「设置与诊断」的「连接设置」。
7. 修改网卡、PS5 地址或上游 DNS。
8. 点击「保存连接设置」。
9. 按[启动接收并修改 DNS](#启动接收并修改-dns)恢复接收。

休眠期间，电脑无法提供 DNS 或接收媒体。唤醒后需要检查接收状态。固件或平台协议变化后，需要按[版本与验证](validation.md)检查接流。
